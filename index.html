Làm được những gì

Sửa chữ tiếng Việt
Bấm vào dòng chữ, gõ lại. Kiểu chữ và màu giữ gần với bản gốc, dấu tiếng Việt hiển thị đúng.
Nhận dạng chữ trên bản scan
File chỉ là ảnh chụp hoặc scan cũng sửa được. App nhận dạng chữ tiếng Việt rồi cho bạn bấm vào từng dòng để sửa.
Quản lý trang
Chèn trang trắng, trang từ PDF khác hoặc ảnh vào đúng vị trí. Xóa, xoay, nhân bản và kéo thả để đổi thứ tự.
Nhiều file cùng lúc
Mỗi file một tab. Chọn nhiều file một lần để mở, hoặc kéo thả từ thư mục vào.
Ảnh và chữ ký
Kéo ảnh thả lên trang, kéo góc để phóng to hoặc thu nhỏ. Vẽ, gõ hoặc tải ảnh chữ ký rồi đặt lên văn bản.
Ký số bằng USB token
Cắm token, chọn chứng thư, nhập mã PIN. Có thể hiện khung chữ ký (tên, ngày giờ, lý do) ngay trên trang. Dùng được cả file .pfx.
In đúng bản đã sửa
In trang hiện tại, các trang đã chọn hoặc toàn bộ tài liệu bằng Ctrl+P.
Lưu đè file gốc
Ctrl+S ghi thẳng lên file đang mở. Có hoàn tác và làm lại cho cả thao tác trên trang.

Cài đặt

  1. Tải bộ càiBấm nút “Tải cho Windows” ở đầu trang.
  2. Chạy file vừa tảiLàm theo hướng dẫn trên màn hình. Mất khoảng một phút.
  3. Mở file PDF bằng appChuột phải vào file PDF, chọn Mở bằng, chọn PDF Editor Pro. Chọn “Luôn dùng ứng dụng này” nếu muốn mở mặc định.

Nếu Windows hiện cảnh báo “Windows protected your PC”, bấm More info rồi Run anyway. Cảnh báo này xuất hiện vì app chưa có chữ ký nhà phát hành, không phải do file bị lỗi.
